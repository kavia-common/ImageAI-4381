# PDF Export Instructions

To generate the consolidated PDF and copy it to the repository root with the requested name:

1) Build the report (Markdown and PDF):
   - python3 scripts/build_security_report.py

2) After successful PDF generation at docs/security/SECURITY-REPORT.pdf, copy it to:
   - ./security_vulnerabilities_report.pdf

Alternatively, if copying manually:
- cp docs/security/SECURITY-REPORT.pdf security_vulnerabilities_report.pdf
